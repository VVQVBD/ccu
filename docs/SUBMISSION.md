## 3. Описание проекта
```
«Азбука жестов» — веб-тренажёр русской дактильной азбуки (алфавит на пальцах) через обычную веб-камеру. Направление: C / FREE (обучение).

Пользователь открывает ссылку, показывает букву рукой перед камерой, а приложение проверяет каждый палец и подсказывает, что исправить. Законченный сценарий: 3 урока → тренировка на скорость (60 с) → экзамен «собери слово» (СОВА, НОРА, СЫР…) → итоги (точность, время, звёзды, трудные буквы) → личные и общие рекорды. Есть аккаунты (Supabase): прогресс сохраняется в облаке, можно играть и без входа.

Жесты: 10 букв РЖЯ — В, А, У, И, Ы, Ш, О, Н, Р, С, плюс жест «указка» (прямой указательный палец) — курсор: наводишь на кнопку и держишь 1,5 с, поэтому всё приложение проходится без клавиатуры и мыши.

Распознавание — своя логика: MediaPipe Hand Landmarker даёт только 21 точку руки, готовый классификатор жестов не используется. Мы считаем угол в суставе каждого пальца (прямой / полусогнут / согнут), касания большого пальца с другими (расстояния делим на размер ладони), отведение большого пальца, поворот ладони (векторное произведение с учётом левой/правой руки), размер и положение руки в кадре. Числа сглаживаются по 5 кадрам.

Режим «ошибка»: каждая буква — список проверок в порядке важности, у каждой своя подсказка. Сначала общие проверки (руку видно, не у края, не далеко/близко, пальцы вверх, ладонь к камере), затем проверки буквы. Первая проваленная проверка — главная ошибка, показываем только её, конкретно: «Выпрями безымянный палец», «Большой палец касается среднего, а нужно — безымянного», «Оставь просвет между большим и указательным — иначе получится «О»». Если рука совпала с другой буквой — «Сейчас похоже на «И». Выпрями указательный палец». Палец с ошибкой на скелете руки подсвечивается красным. Чтобы подсказка не мигала: 1,5 с после новой буквы не ругаемся, ошибка должна держаться 0,8 с, подсказка висит минимум 1,5 с. В итогах буква считается «с ошибкой», если понадобилось 2+ подсказки.

Обратная связь: скелет руки поверх видео (зелёные/красные пальцы), кольцо удержания, схема руки для каждой буквы, звуки (Web Audio), конфетти. Бонусы: своя логика распознавания, аккаунты и таблица рекордов, адаптация под телефон, звук и эффекты.

Стек: HTML/CSS/JavaScript без фреймворков, MediaPipe Tasks Vision (CDN), Supabase, GitHub Pages. Видео не покидает устройство. Заготовок до старта нет.
```
