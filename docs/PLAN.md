## 1. Что строим (одним абзацем)

Веб-приложение, которое учит русской дактильной азбуке через веб-камеру. Пользователь видит эталон буквы, повторяет рукой, система по 21 точке руки (MediaPipe Hand Landmarker) проверяет каждый палец и говорит, что поправить: «согни указательный палец», «соедини кончики большого и безымянного». Сценарий: **Урок → Тренировка → Экзамен «собери слово» → Итоги** (точность, время, звёзды) + рекорды и прогресс в `localStorage`.

Как закрываем критерии кейса:

| Критерий (баллы) | Чем закрываем |
|---|---|
| Работоспособность (30) | 10 букв-жестов, скелет руки и подсветка пальцев, законченный сценарий с итогами, работает по ссылке в браузере |
| Режим «ошибка» (20) | Одна конкретная подсказка по пальцу/ориентации/расстоянию, «похоже на букву X», красная подсветка неправильного пальца |
| Техническая реализация (20) | Своя логика: углы суставов, расстояния, ориентация ладони; понятная структура файлов; README |
| UX/дизайн (15) | Эталон-фото, кольцо удержания, крупные подсказки, управление без мыши |
| Оригинальность (10) | Социально полезная идея: обучение жестовой азбуке |
| Бонусы (5) | Своя логика распознавания, рекорды/прогресс, телефон, звук и эффекты |

Важно по кейсу: «управлять приложением движениями, **без клавиатуры и мыши**» (стр. 1). Поэтому кнопки меню нажимаются **указательным пальцем**: наводим кончик (точка 8) на кнопку и держим `DWELL_MS` = 1500 мс — кнопка заполняется и нажимается. Мышь тоже работает — как запасной вариант.

## 2. Стек и принципы

- Чистый HTML + CSS + JavaScript (ES-модули, `<script type="module">`), **без фреймворков и без сборщика**. Vite не нужен: меньше непонятных файлов для студентов.
- MediaPipe Tasks Vision (`@mediapipe/tasks-vision`) — подключаем с CDN jsDelivr, **с фиксированной версией** (последняя 0.10.x на момент старта; записать её в `config.js` и README). Модель `hand_landmarker.task` — по ссылке Google Storage из официальной документации.
- Используем из MediaPipe **только точки руки**. Готовый Gesture Recognizer **не используем** — распознавание своё.
- Камера работает только по `https://` или на `localhost`. Локально запускаем через простой сервер (`npx serve .` или расширение VS Code «Live Server»), **не** двойным кликом по файлу.
- Деплой: Vercel Hobby (статический сайт) или GitHub Pages — бесплатно. Видео никуда не отправляется, всё считается в браузере.
- Код для студентов 1–3 курса: в начале каждого файла — шапка «за что отвечает, с кем связан»; комментарии по-русски; все пороги — в `config.js` с объяснением.
- Коммиты маленькие, по-русски, от git-аккаунтов студентов.

## 3. Структура файлов

```
index.html              — единственная страница: разметка всех экранов (меню, урок, тренировка, экзамен, итоги, рекорды)
css/style.css           — оформление: цвета, шрифты, экраны, кнопки, кольцо удержания, подсказка
js/main.js              — точка входа: запускает камеру и MediaPipe, в цикле кадров передаёт точки в игру и отрисовку
js/config.js            — все константы и пороги с объяснением (углы, расстояния, время удержания, версия MediaPipe)
js/camera.js            — включает веб-камеру (фронтальную на телефоне), отдаёт <video>, обрабатывает отказ в доступе
js/hand-tracker.js      — загружает MediaPipe Hand Landmarker и на каждый кадр возвращает 21 точку, точки в метрах и какую руку
js/hand-features.js     — из точек считает признаки: угол каждого пальца, касания большого пальца, ориентацию ладони, размер руки
js/letters.js           — эталоны 10 букв (список проверок с подсказками), описания для урока, уроки и слова для экзамена
js/mistakes.js          — сравнивает признаки с эталоном, выбирает ОДНУ главную ошибку, держит подсказку без мигания, «похоже на X»
js/draw.js              — рисует скелет руки на canvas поверх видео, красит правильные пальцы зелёным, ошибочные — красным
js/game.js              — логика режимов: урок, тренировка, экзамен; удержание буквы, таймер, подсчёт точности и звёзд
js/ui.js                — переключение экранов, вывод буквы, подсказки, счёта; кнопки с нажатием «наведи палец и подержи»
js/storage.js           — сохраняет и читает прогресс и рекорды в localStorage
js/sound.js             — короткие звуки через Web Audio API (успех, ошибка, конец) — без аудиофайлов
assets/letters/         — эталонные фото 10 букв (снимает команда своей рукой — без чужих авторских прав)
docs/                   — GESTURES.md, PLAN.md, HOW-IT-WORKS.md, PITCH.md
README.md               — описание для жюри и инструкция запуска
```

Кто что делает (чтобы не было конфликтов в git): один файл — один автор в каждый момент времени. Распределение: **Руслана** — `hand-features.js`, `letters.js`, `mistakes.js` (распознавание и режим «ошибка»); **Камилла** — `index.html`, `css/style.css`, `ui.js`, `draw.js` (интерфейс); **Виктория** — `main.js`, `config.js`, `camera.js`, `hand-tracker.js`, деплой, README; **Мария** — `game.js`, `storage.js`, `sound.js` (сценарий, рекорды, звук).

## 4. Сценарий и правила счёта

**Меню:** «Урок 1 / 2 / 3», «Тренировка», «Экзамен», «Рекорды». Уроки 2 и 3 открываются после предыдущего; Тренировка — после Урока 1; Экзамен — после Урока 2.

**Урок** (уроки и буквы — `GESTURES.md`, раздел 3): по очереди показываем букву — фото-эталон, крупную букву, описание словами. Пользователь держит правильную форму `HOLD_MS` → «Отлично!» + звук → следующая. Времени нет. В конце урока — итоги урока (звёзды).

**Тренировка:** `TRAINING_DURATION_S` = 60 с. Случайные буквы из пройденных (без повтора той же буквы подряд). Каждая засчитанная буква = +1 очко; «Пропустить» — кнопка (палец-наведение), буква идёт как ошибка. Итог — очки, точность, рекорд.

**Экзамен «собери слово»:** `EXAM_WORDS_COUNT` = 3 случайных слова из доступных. Слово показано целиком, текущая буква подсвечена; пользователь показывает буквы по очереди. Если на букве застрял дольше `EXAM_SHOW_REFERENCE_MS` = 15 000 мс — показываем фото-эталон, буква считается «с ошибкой». Итог — время и точность.

**Итоги (для любого режима):**
- Точность = буквы без ошибок / все буквы × 100% (что такое «ошибка» — `GESTURES.md`, раздел 6, п. 8).
- Звёзды: ★★★ — точность ≥ 90%; ★★ — ≥ 70%; ★ — режим пройден до конца.
- Показать: точность, время (для урока и экзамена) или очки (для тренировки), звёзды, «новый рекорд!», и какие буквы давались труднее всего (больше всего подсказок).

**Прогресс и рекорды (`localStorage`):** пройденные уроки и звёзды за них; лучший счёт тренировки; лучшее время экзамена; сколько раз каждая буква получилась. Кнопка «Сбросить прогресс» в разделе «Рекорды».
