# ✋ Азбука жестов

Веб-тренажёр **русской дактильной азбуки** (РЖЯ) через обычную веб-камеру.
Покажи букву рукой — приложение проверит каждый палец и подскажет, что именно поправить.

## Что умеет

- **10 букв-жестов** русской дактильной азбуки: В, А, У, И, Ы, Ш, О, Н, Р, С.
- **Жест «указка»** (прямой только указательный палец) — курсор. Наводишь на кнопку и держишь — она нажимается. Всё приложение проходится **без клавиатуры и мыши**.
- **Скелет руки** поверх видео: правильные пальцы зелёные, ошибочные — красные.
- **Режим «ошибка»**: конкретная подсказка, что не так и как исправить.
- **Сценарий**: Урок 1 → Урок 2 → Урок 3 → Тренировка на скорость / Экзамен «собери слово» → Итоги (точность, время, звёзды).
- **Рекорды и прогресс** сохраняются в браузере, **звуки** без аудиофайлов.

## Как работает режим «ошибка»

1. MediaPipe даёт 21 точку руки. Дальше — **наша логика**: считаем угол в суставе каждого пальца, расстояния между кончиками (делим на размер ладони), ориентацию ладони, размер руки в кадре.
2. Каждая буква — это список проверок в порядке важности (`js/letters.js`), у каждой проверки своя подсказка.
3. Сначала общие проверки (рука видна, не далеко, не у края, пальцы вверх, ладонь к камере), потом проверки буквы. **Первая проваленная проверка — главная ошибка**, показываем только её:
   - «Выпрями безымянный палец»
   - «Большой палец касается среднего, а нужно — безымянного»
   - «Оставь просвет между большим и указательным — иначе получится «О»»
   - «Камера видит тыльную сторону — разверни ладонь к камере»
4. Если рука совпала с другой буквой, говорим об этом: «Сейчас похоже на «И». Выпрями указательный палец».
5. Чтобы подсказка не мигала: первые 1,5 с после новой буквы не ругаемся, ошибка должна держаться 0,8 с, подсказка висит минимум 1,5 с.

Подробно: [docs/GESTURES.md](docs/GESTURES.md).

## Запуск локально

Камера в браузере работает только по `https://` или на `localhost`, поэтому открывать `index.html` двойным кликом нельзя — нужен простой сервер.

```bash
npx serve .
```

Открыть адрес, который покажет команда (обычно http://localhost:3000), и разрешить доступ к камере.
Нужен [Node.js](https://nodejs.org). Другой вариант — расширение VS Code «Live Server».

Отладочная панель с числами по каждому пальцу: добавить `?debug=1` в конец адреса.

## Стек

- HTML + CSS + JavaScript (ES-модули), **без фреймворков и сборки**.
- [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) 1.0.1 — **Hand Landmarker** (только 21 точка руки; готовый классификатор жестов не используем), подключается с CDN jsDelivr.
- Web Audio API — звуки, localStorage — рекорды.
- Видео никуда не отправляется: всё считается в браузере.

## Структура

```
index.html            разметка всех экранов
css/style.css         оформление
js/main.js            точка входа и главный цикл кадров
js/config.js          все пороги и настройки с объяснениями
js/camera.js          включение веб-камеры
js/hand-tracker.js    MediaPipe: 21 точка руки
js/hand-features.js   признаки: углы пальцев, касания, ориентация ладони
js/letters.js         эталоны 10 букв, уроки, слова
js/mistakes.js        режим «ошибка»: засчитать букву или что подсказать
js/draw.js            скелет руки поверх видео
js/game.js            урок, тренировка, экзамен, итоги
js/ui.js              экраны, кнопки, курсор-палец
js/storage.js         прогресс и рекорды
js/sound.js           звуки
docs/                 план, жесты, как устроено
```
